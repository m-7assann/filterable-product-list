# 🌐 تشغيل النظام أونلاين (أكتر من جهاز + حسابات للموظفين)

النظام بيستخدم **Firebase** من جوجل: مجاني للمحلات الصغيرة، ومحتاج حساب Gmail بس.
الخطوات دي بتتعمل **مرة واحدة** وبتاخد حوالي 15 دقيقة.

---

## الخطوة 1: إنشاء مشروع Firebase
1. ادخل على **https://console.firebase.google.com** بحساب Gmail بتاعك.
2. دوس **Create a project** (إنشاء مشروع).
3. اكتب اسم، مثلاً `fabric-office`، ودوس Continue.
4. Google Analytics: اقفلها (مش محتاجينها) ودوس **Create project**.

## الخطوة 2: إضافة تطبيق ويب ونسخ البيانات
1. في صفحة المشروع، دوس على أيقونة الويب **`</>`**.
2. اكتب أي اسم (مثلاً `fabric-office`) ودوس **Register app**.
3. هيظهرلك كود فيه `const firebaseConfig = { apiKey: ... }`. **انسخ الجزء ده كله**.

## الخطوة 3: تفعيل الدخول باسم مستخدم وكلمة سر
1. من القائمة الجانبية: **Build ← Authentication ← Get started**.
2. اختار **Email/Password**، فعّل أول اختيار (Enable)، ودوس **Save**.

## الخطوة 4: إنشاء قاعدة البيانات
1. من القائمة: **Build ← Firestore Database ← Create database**.
2. اختار مكان قريب (مثلاً `eur3 (europe-west)`)، ودوس Next.
3. اختار **Start in production mode** ودوس **Create**.
4. افتح تبويب **Rules**، امسح اللي فيه كله، والصق محتوى ملف **`firestore.rules`** الموجود مع النظام، ودوس **Publish**.

> ⚠️ الخطوة دي مهمة جداً: القواعد دي هي اللي بتمنع أي حد غريب يشوف بياناتك، وبتطبق صلاحيات الموظفين.

## الخطوة 5: ربط النظام
عندك طريقتين:

**الطريقة الأسهل (لو النظام منشور على GitHub Pages):**
افتح ملف `js/config.js` والصق البيانات مكان `null`، بالشكل اللي موجود في الملف كمثال. كده كل جهاز هيفتح الرابط هيبقى مربوط لوحده.

**أو من جوه النظام:**
افتح **الإعدادات ← التشغيل أونلاين**، الصق الكود اللي نسخته، ودوس **ربط وتشغيل أونلاين**.
(الطريقة دي لازم تتعمل على كل جهاز لوحده.)

## الخطوة 6: إنشاء حسابك وحسابات الموظفين
1. هتظهرلك شاشة الدخول. دوس **"أول مرة؟ إنشاء حساب صاحب المكتب"** واعمل حسابك.
   الحساب ده بيتعمل مرة واحدة بس، ومحدش يقدر يعمل حساب صاحب مكتب تاني بعده.
2. من **الإعدادات ← الموظفين والصلاحيات** اعمل حساب لكل موظف، واختار هو يقدر يعمل إيه:

| الصلاحية | معناها |
|---|---|
| عمل فواتير بيع | يبيع توبات ويعمل فواتير |
| فواتير الشراء والموردين | يسجل بضاعة جديدة من الموردين |
| إدارة الأصناف والتوبات | يضيف ويعدل الأصناف والتوبات |
| إضافة وتعديل العملاء والموردين | |
| التحصيل والسداد | يستلم فلوس من العملاء ويدفع للموردين |
| المصروفات | |
| التقارير والأرباح وأسعار الشراء | يشوف المكسب وسعر الشراء |
| تعديل وحذف الفواتير والحركات | يعدل أو يحذف فواتير ومدفوعات قديمة |

أي موظف يقدر يشوف المخزن والعملاء وفواتير البيع. الإعدادات والموظفين لصاحب المكتب بس.

## نقل البيانات اللي على الجهاز
لو كنت بتستخدم النظام قبل الربط:
1. **قبل الربط:** من الإعدادات دوس **تحميل نسخة احتياطية**.
2. **بعد الربط والدخول:** من الإعدادات دوس **استرجاع نسخة احتياطية** واختار الملف.

---

## أسئلة شائعة
- **لو النت قطع؟** تقدر تكمل شغل عادي، والبيانات هتتبعت لما النت يرجع. (لازم تكون فتحت النظام مرة وانت متصل.)
- **موظف ساب الشغل؟** من الإعدادات دوس **إيقاف** جنب اسمه، ومش هيقدر يدخل تاني.
- **موظف نسي كلمة السر؟** أوقف حسابه واعمله حساب جديد باسم دخول مختلف.
- **التكلفة؟** الخطة المجانية (Spark) بتكفي محل أو مكتب بسهولة.
- **ملحوظة:** إخفاء أسعار الشراء عن الموظفين بيتم من شاشات النظام. لكن موظف شاطر في البرمجة ممكن يوصلها من أدوات المتصفح، فمتديش حسابات غير لناس بتثق فيهم.
